Yearbook Website

Type: Company project

Primary stack: HTML, CSS, basic JavaScript

Live site: yearbook.chaldal.com

Project Goal

The goal was to create a digital yearbook that helps students find classmates quickly and view organized class memories on phones and desktops. I wanted the interface to stay simple while still handling many profile cards and media sections.

What I Built

I created reusable card components for student profiles, section-based grouping by batch and department, and a responsive layout so the same content works across multiple screen sizes. I also added consistent heading styles and spacing rules to make the large content set easier to scan.

Challenges and Decisions

The largest challenge was preventing the page from becoming visually crowded once many entries were added. I solved this by using predictable card widths, grouping content into smaller sections, and reducing decorative styles in dense areas. I also tested how long names and mixed image dimensions affected alignment.

Quality and Accessibility Work

I used semantic elements where possible, kept color contrast readable, and added descriptive alternative text for images. Keyboard navigation was checked for links and interactive elements so users can move through content without a mouse.

Result and Learning

The final result is a maintainable static site structure that can be extended with more student records without redesigning the layout. This project improved my understanding of information hierarchy, responsive CSS, and content organization for real users.
